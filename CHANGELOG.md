# Журнал изменений

Все заметные изменения проекта фиксируются в этом файле.

## [Unreleased]

- Добавлен единый профиль памяти: bufferSize=64 КиБ, connIdle=180, клиентский XMUX pool=1 с ограниченным повторным использованием.
- Добавлен `optimize-xhttp-memory.sh` для обновления работающей установки, online-резервной копии SQLite, проверки сохранения и повторного запуска без изменений.
- Восстановление сохраняет настройки существующего inbound, все short IDs и лимиты; неполные REALITY-ключи больше не заменяются автоматически.
- Добавлены регрессионные проверки сохранности полей, идемпотентности и отказа для неверного inbound.
- Резервирование работающей SQLite переведено на `.backup`; временный установщик создаётся через `mktemp`; ошибка `swapoff` прекращает откат с сохранением файла.
- Повторный запуск после незавершённого bootstrap сохраняет частичную установку вместо автоматического удаления.

- Исправлена совместимость с 3x-ui 3.5.0: поле клиента `tgId` передаётся числом, поэтому standalone inbound создаётся без ошибки JSON.
- Исправлена обработка вставленного домена и ответов WARP: случайные служебные символы на границах ввода больше не мешают установке.
- REALITY использует поле `target`, поэтому «Цель» видна в 3x-ui и inbound можно редактировать через веб-панель.
- Название inbound совпадает с введённым именем ноды или сервера; технический суффикс убран.
- Файлы состояния нод сохраняются как `/root/3xui-node-*.env`.
- README содержит одну команду запуска; подготовлены материалы для первого публичного релиза.

## [0.1.0] — планируется

Первый публичный выпуск будет создан только после успешной установки и проверки на чистом VPS с доменом.
